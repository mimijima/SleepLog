# SleepLog 操作モックアップ

画面の構成と遷移を確認するための、低解像度の操作モックアップです。
実際の認証・保存・分析は行いません。

## 開き方

ブラウザで [index.html](index.html) を開いてください。

## 確認できる主な流れ

- ログイン画面でコード送信後、ログインする
- 記録画面で就寝を記録し、起床操作部で起床を記録する
- 記録タブとグラフタブを移動する
- グラフの行から睡眠一覧を開き、追加・編集・削除する
- 年月選択、右上メニュー、プライバシーポリシー、ログアウト確認を開く

見た目の色・余白・グラフの詳細な表示量は、次の画面デザイン工程で決めます。
