# 開発のおおまかな流れ

1. 目的・機能候補・優先順位を決める  
   アプリで達成したいこと、将来を含めた機能候補、最初に作る範囲を整理する。

2. 最初の完成版の仕様を固める  
   記録項目、入力方法、集計ルール、公開範囲などを決める。

3. 画面仕様と操作フローを決める  
   ログイン、記録、グラフ、手動追加・編集の画面と操作の流れを決める。

4. 技術構成と公開方法を選ぶ  
   認証サービス、データベース、ホスティングなどを決める。

5. 実装の順番を決めて開発する  
   最初の完成版に必要な機能から実装する。

6. 実際に使い、必要な機能だけ追加する  
   数日〜数週間使い、不便な点や必要性が確認できた機能を追加する。
