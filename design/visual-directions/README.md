# v0 視覚デザイン

この文書には、v0 で採用した画面デザインと視覚素材の実装方針を記録する。機能、表示内容、操作、状態変化の仕様は、[v0 仕様](../../docs/v0/specification.md)を参照する。

このフォルダの画像は、画面の雰囲気、構成、状態変化を共有するための参考資料であり、実装用の素材そのものとは限らない。

## 共通方針

-   文字、色、大きさ、選択状態など、画面や状態に応じて調整する要素は、HTML・CSS・SVGで表現する。
-   手描きの質感そのものが必要なイラストにはPNGを使用し、同じ画面内では線や塗りの質感を統一する。
-   タブ・メニューなどのアイコンはSVGを使い、CSSで色・大きさ・選択状態を調整できるようにする。

#### 素材・表現の実装方針

-   ベッド・植物・家具・窓枠・窓の外の景色に加え、動かないロールカーテンの巻き取り棒とひもを含む部屋全体は、同じ手描きの質感を保つPNG背景素材として用意する。窓外の景色は背景に含め、起床操作中も表示してよい。
-   ロールカーテンの下端のバーは、部屋背景とは別のPNG素材として用意する。カーテン本体と下端のバーの開閉、睡眠中の暗さ・起床時の明るさの変化はCSSで動かす。
-   部屋全体の明るさ、窓から射す光、ベッドサイドのライトの灯りは、CSSの半透明レイヤーやグラデーションで表現する。
-   就寝ボタンは、CSSによる円形の土台に、SVGの月アイコンと手描き風の不均一な縁取りを重ねる。ボタン名はHTMLのテキストとして配置し、デザインに合うフォントを使う。
-   アプリ名と起床直後の挨拶はHTMLのテキストとして配置する。睡眠中から起床直後への変化に合わせ、背景の暗さとは別にCSSで文字色と影を変化させる。

#### 素材・表現の実装方針

-   グラフの棒・目盛線・曜日色などの情報表示は、画像ではなくHTMLとCSS、必要に応じてSVGで描画する。

### 年月選択

| ファイル | 内容 | 画像から読み取る実装上の要点 |
| --- | --- | --- |
| `sel-year-month-grid.png` | 年月選択 | グラフ画面を薄く暗くして中央にオーバーレイを開く。年を縦スクロールで選び、1月から12月までの一覧から月を選ぶ。月選択ボタンを押すと、選んだ年月のグラフへ移動する。キャンセルボタンでは元の表示位置へ戻る。 |

#### 採用理由

-   主な利用では数年前までを選べればよく、年の候補を多数同時に表示する必要性が低い。
-   1 月から 12 月までを一覧できるため、目的の月を探して直接選びやすい。
-   月選択ボタンを押した時点で移動でき、確定ボタンを追加する方式より操作数を減らせる。
-   年月を常時 2 列のリストで表示する案より画面を簡潔に保ちつつ、ホイールだけで年と月を選ぶ案より月の候補を見渡しやすい。
-   独自のプルダウンを作らずに済み、端末ごとの標準プルダウン表示の違いを避けられる。
