# v0 視覚デザイン

この文書には、v0 で採用した画面デザインと視覚素材の実装方針を記録する。機能、表示内容、操作、状態変化の仕様は、[v0 仕様](../../docs/v0/specification.md)を参照する。

このフォルダの画像は、画面の雰囲気、構成、状態変化を共有するための参考資料であり、実装用の素材そのものとは限らない。

## 共通方針

-   文字、色、大きさ、選択状態など、画面や状態に応じて調整する要素は、HTML・CSS・SVGで表現する。
-   手描きの質感そのものが必要なイラストにはPNGを使用し、同じ画面内では線や塗りの質感を統一する。
-   タブ・メニューなどのアイコンはSVGを使い、CSSで色・大きさ・選択状態を調整できるようにする。

#### 素材・表現の実装方針

-   ベッド・植物・家具・窓枠・窓の外の景色に加え、動かないロールカーテンの巻き取り棒とひもを含む部屋全体は、同じ手描きの質感を保つPNG背景素材として用意する。窓外の景色は背景に含め、起床操作中も表示してよい。
-   ロールカーテンの下端のバーは、部屋背景とは別のPNG素材として用意する。カーテン本体と下端のバーの開閉、睡眠中の暗さ・起床時の明るさの変化はCSSで動かす。
-   部屋全体の明るさ、窓から射す光、ベッドサイドのライトの灯りは、CSSの半透明レイヤーやグラデーションで表現する。
-   就寝ボタンは、CSSによる円形の土台に、SVGの月アイコンと手描き風の不均一な縁取りを重ねる。ボタン名はHTMLのテキストとして配置し、デザインに合うフォントを使う。
-   アプリ名と起床直後の挨拶はHTMLのテキストとして配置する。睡眠中から起床直後への変化に合わせ、背景の暗さとは別にCSSで文字色と影を変化させる。

### 年月選択

| ファイル | 内容 | 画像から読み取る実装上の要点 |
| --- | --- | --- |
| `sel-year-month-grid.png` | 年月選択 | グラフ画面を薄く暗くして中央にオーバーレイを開く。年を縦スクロールで選び、1月から12月までの一覧から月を選ぶ。月選択ボタンを押すと、選んだ年月のグラフへ移動する。キャンセルボタンまたはオーバーレイ外の背景操作部では、元の表示位置へ戻る。 |

#### 採用理由

-   主な利用では数年前までを選べればよく、年の候補を多数同時に表示する必要性が低い。
-   1 月から 12 月までを一覧できるため、目的の月を探して直接選びやすい。
-   月選択ボタンを押した時点で移動でき、確定ボタンを追加する方式より操作数を減らせる。
-   年月を常時 2 列のリストで表示する案より画面を簡潔に保ちつつ、ホイールだけで年と月を選ぶ案より月の候補を見渡しやすい。
-   独自のプルダウンを作らずに済み、端末ごとの標準プルダウン表示の違いを避けられる。

### 睡眠一覧

| ファイル | 表す状態 | 画像から読み取る実装上の要点 |
| --- | --- | --- |
| `lst-dat-v5.png` | 4件の睡眠記録がある状態 | 選択したグラフ行を示す「5月15日（水）の睡眠記録」をタイトルとして表示する。各記録は「就寝日時 → 起床日時」と睡眠時間の2段で表示し、編集と削除は2段目の右側に正方形のアイコンボタンとして置く。 |
| `lst-one-v3.png` | 1件の睡眠記録がある状態 | 4件表示時と同じタイトル領域を使い、内容量に合わせてオーバーレイ全体の高さを縮める。 |
| `lst-emp-v3.png` | 睡眠記録がない状態 | 同じタイトルの下に新規追加ボタンと閉じるボタンだけを表示し、空の一覧領域や説明文は設けない。 |

#### 実装上の方針

-   タイトルは、選択したグラフ行の表示区切りの開始日と曜日を表すものであり、睡眠日の定義ではない。
-   睡眠記録の件数にかかわらず、タイトル領域の高さ、上下余白、文字位置は共通のCSSで固定する。件数に応じて変化させるのは一覧領域とオーバーレイ全体の高さとする。
-   「就寝」「起床」のラベルを各記録で繰り返さず、日時の間の矢印で開始から終了への流れを示して、横幅を日時に使う。実装では読み上げ用の名前として就寝日時・起床日時を残す。
-   1件を1つの一覧項目として保ちながら、日時を1段目、睡眠時間と操作を2段目に分ける。日時には一覧項目の横幅全体を割り当て、読みやすさを優先する。
-   編集・削除を正方形のアイコンボタンにして横幅を抑え、グラフ画面の初期表示へ戻る操作部と共通する視覚表現にする。実装ではアイコンだけに依存せず、操作名を読み上げられるようにする。
-   新規追加ボタンはすべての睡眠記録より後に置き、記録が多い場合は一覧と一緒にスクロールさせる。未確認の記録が下に残ったまま、未登録だと誤認して追加することを防ぐ。
-   記録数が増えた場合もオーバーレイ全体は伸ばし続けず、睡眠記録と新規追加ボタンの領域だけをスクロール対象にする。閉じるボタンを下部に固定し、一覧の位置にかかわらず元のグラフへ戻れるようにする。
