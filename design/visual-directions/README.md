# 視覚デザイン案

このフォルダは、v0 の画面デザインを検討するための画像案を置く。実装用の素材そのものではなく、画面の雰囲気、構成、状態変化を共有する目的で使う。

実装に使う素材の方針は、[v0 仕様](../../docs/v0/specification.md#視覚素材の方針)を参照する。

## 採用方向の記録画面

| ファイル | 表す状態 | 画像から読み取る実装上の要点 |
| --- | --- | --- |
| `rec-pre-bedroom-v2.png` | 開始前 | 北欧風の手描きの部屋を背景にする。左上に小さめのアプリ名、右上にメニューボタンを置く。大きな就寝ボタン、追加ボタン、下部タブを表示する。 |
| `rec-slp-bedroom-v2.png` | 睡眠中 | 同じ部屋を暗い青緑系にする。通常のボタンとタブは隠す。画面下部に、上方向へのスワイプで起床日時を記録できることを伝える「上にスワイプして起床」の控えめな操作案内を表示する。 |
| `rec-mid-bedroom.png` | 起床操作中 | スワイプに合わせてロールカーテンが中ほどまで上がり、窓外の景色を含む部屋が徐々に明るくなる。 |
| `rec-wak-bedroom-v3.png` | 起床直後 | ロールカーテンを上げ切り、朝の窓外と「おはようございます」の短時間の完了表示を画面中央に出す。文字は背景を隠さずに読みやすい色・控えめな影または縁取りで表示する。通常のボタンとタブは表示しない。 |

## グラフ画面

| ファイル | 内容 | 画像から読み取る実装上の要点 |
| --- | --- | --- |
| `grp-dense-v4.png` | グラフ画面の現在案 | 20 日程度を連続した背景の横棒グラフで表示する例。実際に1画面へ表示する日数は固定せず、端末の縦横比・文字サイズ・操作性を確認して決める。棒は角丸なし、右端の 16:00 も他の目盛線と同じ細い点線にする。曜日は月〜金を通常色、土曜を青系、日曜を赤系で表示する。年月選択操作部と、その横に置く初期表示へ戻るカレンダーアイコンの操作部は、同程度の大きさにする。下部タブの選択状態は、アイコンと文字の色で区別する。装飾の葉は使わない。 |
